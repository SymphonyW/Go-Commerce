# 文档导航

该目录用于存放 Go Commerce 的补充文档。

| 文档 | 用途 |
| --- | --- |
| [`TECHNICAL_DOCUMENT.md`](TECHNICAL_DOCUMENT.md) | 架构设计、交易链路、消息机制、权限模型 |
| [`API_Documentation.md`](API_Documentation.md) | 面向阅读的 REST API 说明 |
| [`INTERVIEW.md`](INTERVIEW.md) | 项目面试讲解与回答思路 |
| [`../openapi.yaml`](../openapi.yaml) | 机器可读 OpenAPI 3.0 描述 |

推荐阅读顺序：想快速理解项目，先看根目录 README；想看设计，查看 `TECHNICAL_DOCUMENT.md`；想调接口，查看 `API_Documentation.md` 或 `../openapi.yaml`；想准备面试，查看 `INTERVIEW.md`。
